Visual Plan Architecture Documentation
======================================

Welcome to the Visual Plan Architecture documentation. This project is an AI-powered web application for generating visual content, including images and diagrams.

Overview
--------

Visual Plan is a Next.js application that uses OpenAI's GPT models to generate visual plans and create visual content. The application supports two main modes:

- **Art Mode**: Generate beautiful images using AI
- **Diagram Mode**: Create scalable SVG diagrams and flowcharts
