Type Definitions
================

Location: ``lib/types.ts``

The application uses TypeScript interfaces to define data structures for visual plans and API requests/responses.

Core Types
----------

VisualElement
~~~~~~~~~~~~~

Represents a single visual element in a plan.

.. code-block:: typescript

   interface VisualElement {
      id: string
      type: "shape" | "text" | "image" | "icon"
      position: { x: number; y: number }
      size: { width: number; height: number }
      properties: Record<string, any>
   }

**Properties:**
   - ``id``: Unique identifier for the element
   - ``type``: Type of visual element
   - ``position``: X and Y coordinates
   - ``size``: Width and height dimensions
   - ``properties``: Additional properties as key-value pairs

VisualPlan
~~~~~~~~~~

Represents a complete visual plan generated by the AI.

.. code-block:: typescript

   interface VisualPlan {
      id: string
      mode: "art" | "diagram"
      title: string
      description: string
      prompt: string
      elements: VisualElement[]
      metadata: {
         style: string
         composition: string
         colors: string[]
         lighting?: string
      }
      createdAt: Date
      updatedAt: Date
   }

**Properties:**
   - ``id``: Unique identifier for the plan
   - ``mode``: Generation mode (art or diagram)
   - ``title``: Title of the visual
   - ``description``: Description of the visual
   - ``prompt``: Original user prompt
   - ``elements``: Array of visual elements
   - ``metadata``: Style and composition information
   - ``createdAt``: Creation timestamp
   - ``updatedAt``: Last update timestamp

Request Types
-------------

ArtGenerationRequest
~~~~~~~~~~~~~~~~~~~~

Request structure for art generation.

.. code-block:: typescript

   interface ArtGenerationRequest {
      prompt: string
      style?: string
      aspectRatio?: "1:1" | "16:9" | "9:16"
   }

**Properties:**
   - ``prompt``: Required text description
   - ``style``: Optional art style specification
   - ``aspectRatio``: Optional aspect ratio (defaults to 1:1)

DiagramGenerationRequest
~~~~~~~~~~~~~~~~~~~~~~~~~

Request structure for diagram generation.

.. code-block:: typescript

   interface DiagramGenerationRequest {
      prompt: string
      diagramType?: string
      layout?: string
   }

**Properties:**
   - ``prompt``: Required text description
   - ``diagramType``: Optional diagram type specification
   - ``layout``: Optional layout algorithm specification

Response Types
--------------

GenerationResult
~~~~~~~~~~~~~~~~

Standard response structure for generation operations.

.. code-block:: typescript

   interface GenerationResult {
      success: boolean
      visualPlan: VisualPlan
      outputUrl: string
      format: string
   }

**Properties:**
   - ``success``: Whether the generation was successful
   - ``visualPlan``: The generated visual plan
   - ``outputUrl``: URL to the generated output
   - ``format``: MIME type of the output (e.g., "image/png", "image/svg+xml")

Usage
-----

These types are used throughout the application to ensure type safety:

- API route handlers use them for request/response validation
- React components use them for prop typing
- Utility functions use them for data transformation

Example:

.. code-block:: typescript

   import { ArtGenerationRequest, GenerationResult } from "@/lib/types"

   async function generateArt(
      request: ArtGenerationRequest
   ): Promise<GenerationResult> {
      // Implementation
   }
